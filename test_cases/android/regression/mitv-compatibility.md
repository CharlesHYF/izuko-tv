# MiTV API 23 兼容验证

## 自动化用例

| 用例 | 输入 | 预期 |
| --- | --- | --- |
| 低内存首次使用 | 空设置存储、兼容配置 | 弹幕、视频预览、会话保留关闭，视觉档为流畅 |
| 设置开关持久化 | 开启弹幕、预览、会话保留后重建仓库 | 用户选择保持开启，其他低内存设置保持 |
| 普通构建默认值 | 空设置存储、标准配置 | 保留原有默认值 |
| 低内存回看缓冲 | 创建低内存 LoadControl | 已播内容保留时间为零 |
| 限速资源反复重缓冲 | 低内存配置，多次重缓冲 | 不等待超过缓冲预算的门槛，不开启额外并发连接 |
| 实际依赖最低系统 | 解析 release 运行依赖 | 所有 AAR 最低 API 不高于 23 |
| 实际依赖 ABI | 解析含 JNI 的 release 运行依赖 | 提供 armeabi-v7a 原生库 |
| APK 构建 | API 23、armeabi-v7a TV 变体 | 编译、资源合并、DEX 和打包成功 |

执行方式见 `tools/docker/mitv/README.md`。运行日志保存在未入库的 `artifacts/mitv`，不能以用例文档本身作为通过证据。

## 目标电视用例

以下用例必须在 MiTV4-ANSM0 上执行；host tests 和其他设备不能替代。

1. 安装、冷启动，使用系统默认语言及切换应用语言，确认没有缺失系统类或原生符号错误。
2. 连续和长按方向键，浏览首页、搜索结果、详情及设置；确认无焦点丢失、输入积压。
3. 分别播放设备可硬解的 H.264 和 H.265 资源，检查字幕、音轨、暂停、快进快退及换源。
4. 连续播放 30 分钟并反复切集，记录 Java 堆、PSS、系统内存、卡顿和进程退出情况。
5. 逐项开启弹幕、视频预览、视觉效果、磁盘缓存及后台会话，重启应用确认持久化，并记录各项性能代价。
6. 核查本地 BT 与自动验证码识别不出现在可用功能中，人工验证码处理有可达入口。
7. 记录 APK 大小、安装后占用及缓存增长；剩余空间不足时验证错误提示和清理行为。
